# Story 456: Add items to cart and check out

As a shopper, I want to add products to my cart and place an order,
so that I can buy what I need.

## Acceptance criteria
- The product list shows Notebook, Pen and Backpack
- Clicking "Add to cart" on a product increases the cart count by 1
- Clicking "Checkout" with items in the cart shows "Order placed"
- Clicking "Checkout" with an empty cart shows "Cart is empty"

(Stands in for an Azure DevOps work item. With ADO MCP the agent would read this itself.)
