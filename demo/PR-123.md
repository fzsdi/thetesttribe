# PR 123: Move checkout button into Order summary

Intentional UI change from the design team.

- The "Checkout" button is renamed "Place order"
- It moves into a new "Order summary" section
- Button id changes from `checkout-btn` to `place-order-btn`
- Behaviour is unchanged: with items in the cart it shows "Order placed", with an empty cart it shows "Cart is empty"

Changed file: `app/index.html` (new version in `demo/pr-123-index.html`)
